# Screen Off

Иконка на рабочем столе: нажал, и экран сразу заблокировался.

## Как получить APK (без Android Studio)

1. Зайди на github.com, создай бесплатный аккаунт (если нет).
2. Создай новый репозиторий (New repository), название любое, например `ScreenOff`.
3. Нажми «uploading an existing file» и загрузи ВСЁ содержимое папки проекта
   (вместе с папкой `.github`; если она не видна, включи показ скрытых файлов).
4. Открой вкладку **Actions**: сборка запустится сама (3-5 минут).
5. Открой завершённую сборку, внизу в разделе **Artifacts** скачай `ScreenOff-apk`.
6. Распакуй zip, перекинь `app-debug.apk` на телефон и установи.

## Первый запуск на телефоне

1. Нажми иконку «Screen Off»: откроются настройки специальных возможностей.
2. Установленные приложения → Screen Off → включить.
3. Вернись на рабочий стол и нажми иконку: экран блокируется.

Если Android блокирует включение службы («Ограниченные настройки»):
Настройки → Приложения → Screen Off → три точки сверху → «Разрешить ограниченные настройки».
